# Video Workflow · 让想法，开拍

产品是本仓库的创作流程。影片中的“显影机器”是解释工作方式的视觉隐喻，不是实际硬件或软件界面。

## 三种方向

| 方案 | 核心 | 判断 |
|---|---|---|
| A 无限剪辑带 | 从散乱卡片组装出胶片 | 直观，但容易再次落入“浮动卡片” |
| B 桌面微型片场 | 摄影棚、参考墙和剪辑台在桌上展开 | 内容丰富，但 40 秒需要较多环境说明 |
| **C 影片显影机** | 胶片进入精密机器，借助色片、分镜、立体化、修改和声轨装置，展示创作工序 | 产品关系清楚，允许微距、拆解、节奏反差和整体揭示；采用 |

## 美术与声音

暖灰摄影棚、黑色阳极金属、奶油色纸、橙色滚轮、少量绿色进度灯。主角是一条真正有弯曲表面的胶片：带齿孔、画格和可读小图。避免一直在远景看整台机器；先展示细节，再揭示工作方式。使用 Three.js 的真实光照、阴影和反射，宏观/微观有明确景别差。

程序配乐为默认路径。机械锁扣、卷片、扫光和音符与动作对应；至少一处明确暂停，再回到完整编曲。配乐和 Foley 均保留源码。

## 镜头计划

| 时段 | 主体行为、摄影及信息 |
|---|---|
| 0–4 | 超近景：胶片画格经过橙色滚轮，镜头揭示轮毂、齿孔与材料；先发生动作，再给片名 |
| 4–9 | 侧面跟随：三块色片/参考框围绕画格，形状与色彩被确定；观众看到选择的作用 |
| 9–14 | 画格展开成分镜，镜头抬高露出纸面与定位结构；留下修改的空间 |
| 14–20 | 胶片开始穿过滚轮，纸上的圆形母题升成立体运动对象；相机环绕，画面拥有空间与时间 |
| 20–23.33 | 停机，悬停画格被微调后归位；音乐与机制一起停顿、重新启动 |
| 23.33–28 | 音符柱随鼓点抬落，声轨接入画格下方；“音乐，也能本地生成” |
| 28–33.33 | 快速插入：画格、同步声轨、成片出口；沿胶片环切换细节，镜头拉出揭示全系统 |
| 33.33–40 | 镜头拉出，为产品信息留出空间，产品名、核心承诺与仓库地址；动势减弱、尾音自然结束 |

关键验证段落：滚轮驱动的真实弯曲胶片与镜头推进，结合开场微距和末尾全景。先检查光照、材质、景别和画格可读性，再输出整片。成片不足应如实记录，不能仅凭采用 3D 就宣称超过参考。
